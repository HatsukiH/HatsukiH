# 我的博客 · 使用说明

这是基于 [fuwari](https://github.com/saicaca/fuwari) 改造的「古早二次元」个人博客。
改造是**中度**的：保留 fuwari 的布局与交互骨架，只重做了配色、圆角、字体、侧栏挂件与页脚装饰。

---

## 一、最常改的几个地方

| 想改什么 | 改哪个文件 |
| --- | --- |
| 博客名 / 副标题 / 主题色相 | `src/config.ts` → `siteConfig` |
| 顶部导航（含「友链」入口） | `src/config.ts` → `navBarConfig` |
| 头像 / 昵称 / 简介 / 社交图标 | `src/config.ts` → `profileConfig` |
| 友情链接数据 | `src/config.ts` → `friendsConfig` |
| 配色 / 圆角（做旧皮肤） | `src/styles/variables.styl` |
| 字体 / 分割线 / 纸张肌理等装饰 | `src/styles/retro.css` |
| 页脚文案（运行天数等） | `src/components/Footer.astro` |
| 「关于」页面内容 | `src/content/spec/about.md` |

所有需要你替换的占位内容，都在 `src/config.ts` 里用注释标了 `占位`。

## 二、写一篇新文章

文章放在 `src/content/posts/`，一个 `.md` 文件就是一篇。新建文件后填 frontmatter：

```markdown
---
title: 文章的标题
published: 2026-10-13
description: 一句话摘要，会显示在首页卡片上
image: ""            # 封面图，可留空
tags: [随笔, 记录]
category: 随笔        # 目前分三类：日记 / 随笔 / 技术
draft: false          # true 则不会发布
---

正文从这里开始……
```

三类内容的区别只在于 `category` 字段，用于首页/归档的分类筛选。

用命令行新建（会自动带上 frontmatter 模板）：

```bash
pnpm new-post 我的新文章
```

> 注：本项目当前环境用 **npm** 装的依赖（见文末说明），如果 `pnpm` 不可用，
> 直接手动新建 md 文件即可，效果一样。

## 三、本地预览

```bash
npm run dev        # 或：pnpm dev
```

打开 http://localhost:4321 即可。改动会热更新。

生产构建（会做类型检查 + Pagefind 搜索索引）：

```bash
npm run build
```

产物在 `dist/`，可用 `npm run preview` 本地预览构建结果。

## 四、当前已做的改造清单

**做旧配色（`src/styles/variables.styl`）**
- 底色改为暖米白「纸感」，卡片近白偏暖，暗色模式同样偏暖。
- 强调色固定为褪色靛青（`themeColor.hue = 265` 且 `fixed: true`），整体降饱和。
- `--radius-large` 改为 `0.25rem`，配合 `retro.css` 里对 `rounded-*` 的收紧，做出小直角卡片。

**字体（`src/layouts/Layout.astro` + `src/styles/retro.css`）**
- 正文字体：霞鹜文楷（LXGW WenKai Screen），通过 CDN `lxgw-wenkai-screen-webfont` 引入。
- 代码块保持等宽字体，不受正文影响。
- 若 CDN 不可用，会回退到 `Noto Serif SC / Songti SC / serif`。

**侧边栏挂件（`src/components/widget/`）**
- `SiteStats.astro` — 本站已运行天数 + 不蒜子访客/访问量。
- `Friends.astro` — 友情链接墙（数据来自 `friendsConfig`）。
- `BgmPlayer.svelte` — 背景音乐播放器，**默认不自动播放**，音频在 `public/music/`。
- 注册位置：`src/components/widget/SideBar.astro`。

**装饰（`src/styles/retro.css`）**
- 纸张肌理：暖色高光 + 边缘暗角 + 极淡噪点（纯 CSS，无图片依赖）。
- 挂件标题下加虚线；引用块左侧虚线；正文 `hr` 改为虚线；卡片改用细描边。
- 友链头像缺失时自动回退到 `public/images/link-avatar.svg`。

## 五、待办 / 可继续调整

- [ ] 友链数据 `friendsConfig` 换成真实的小站。

- [ ] 部署时再配置 `astro.config.mjs` 的 `site` / `base`（GitHub Pages 需要 `base`），目前按纯本地预览配置。

## 六、环境备注（重要）

本机是 Windows，`pnpm` 在该环境下无法建立依赖软链接（`node_modules` 会变成空目录），
因此依赖实际是用 **npm** 安装的（`package-lock.json` 为准）。

- 用 `npm run dev` / `npm run build` 最稳；`pnpm` 命令在本机可能不工作。
- 首次安装若遇到 esbuild / sharp 的构建脚本被拦截，可加
  `--config.dangerously-allow-all-builds=true` 放行。
- 安装过程遗留的 `node_modules_old_*`、`node_modules_pnpm_junk` 空目录可以手动删除（不影响运行）。
